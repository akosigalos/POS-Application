# Build Prompts and Implementation Scope

## Project Goal

Build a browser-based, self-service POS kiosk that is easy to use on desktop, tablet, and mobile touchscreens.

## Core Build Requirements

- Use separate HTML, CSS, and Vanilla JavaScript files.
- Keep controls large, clear, and touch friendly.
- Support item selection, cart management, payment simulation, receipts, and transaction reset.
- Preserve completed features while extending the application.

## Feature Prompts by Milestone

1. **Base kiosk:** Create product cards, a cart, item quantities, order summary, payments, and a digital receipt.
2. **Product discovery:** Add categories, product search, and an empty result message.
3. **Pricing:** Add No Discount, Student Discount (10%), Senior Citizen/PWD Discount (20%), and 12% VAT.
4. **Reports:** Save completed transactions locally, then provide order history and sales totals by payment method.
5. **Feedback:** Collect a required one-to-five-star rating and optional written feedback, then summarize saved responses.
6. **Receipt output:** Add print-only receipt styling and downloadable text receipts with all transaction details.

## Constraints

- Do not use a real payment gateway.
- Do not save sensitive customer payment information.
- Do not remove working POS features when introducing a new feature.
- Keep the interface responsive and accessible.
